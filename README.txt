炼化实验室 · 石油加工交互案例
============================

完整的作业要求整理、项目说明、案例对照、导入规则和提交清单见：
docs/项目说明与作业提交指南.md

GitHub 首页说明见：
README.md

所属类别：第13类，加工。

打开网站
--------
直接双击本目录的 index.html。无需安装依赖，无后端，无CDN。
也可以把本目录完整发布到支持静态HTML的网站空间。

网站内容
--------
加工类别全部5个场景，每个包含专业背景、案例流程与交互演示：
1. 常减压装置操作优化：二次岭回归 + 约束网格搜索。
2. 催化裂化产物预测：距离加权k近邻回归。
3. 炼化设备预测性维护：多变量高斯异常检测。
4. 化验数据智能审核：孤立森林 + 范围规则，支持CSV。
5. 产品质量在线软测量：岭回归 + 校准残差区间，支持时间播放。

提交目录
--------
index.html            网站入口
assets/               页面、图解、导入器和内置案例包
cases/                可分别压缩提交的5个独立案例文件夹
tools/                可选的内容构建与检查脚本
package.json          可选脚本入口，无第三方依赖

案例导入
--------
点击网站右上角“添加案例”，选择或拖入完整案例文件夹，校验后添加。
案例格式沿用老师原网站：case.json + demo/。sceneId保持原编号r1—r5。
原示例firstbreak-pick-case也可按原样导入本网站。
同id案例已存在时，改成不同id再导入，或先在案例库移除已有案例。
导入结果保存在当前浏览器；网站自带的5个案例已打包，首次访问即可使用。
导入时保留流程图与算法等可选展示字段，旧格式案例仍可使用。

交互说明
--------
同一案例中切换“专业背景 / 案例流程 / 交互演示”会保留参数、流程步骤和当前批次。
离开案例时清理演示；软测量播放在切走时暂停。
案例库的搜索和筛选条件写入网址，可刷新恢复，也可点击“清空筛选”。
手机端点击顶栏“导航”打开页面菜单。
化验审核支持只看待复核、按分数排序，并逐条展示模型阈值与范围规则依据。
用户CSV没有真实标签时，不显示检出率或标记精确率。

修改与构建（只在改代码时需要Node.js）
-----------------------------------
1. 修改cases/下的case.json和demo/demo.js。
2. 如需修改共用数值函数或样式，编辑tools/engine.js和tools/demo.css。
3. 运行 node tools/build.mjs，更新共用文件、案例包和index.html中的内容版本。
4. 运行 node tools/check.mjs，进行数值与案例契约检查。

tools/create-content.mjs用于重新生成维护的清单内容。
手工修改case.json后不要运行此命令，否则会用脚本内容重新生成清单。

数据说明
--------
演示数据均为教学合成数据。训练、校准、测试用途分别说明。
误差、分数、预测和推荐由程序实际计算，不是固定展示结果。
教学范围、目标权重与阈值不是工业产品标准，不直接用于生产操作。
专业与算法参考链接在每个案例的专业背景页中列出。

压缩提交
--------
将cases/下每个“大类别-小类别”文件夹分别压缩即可。
请保留case.json与demo/的相对位置。网站整体另作为静态项目保存发布。
