# 炼化实验室：石油加工交互案例

这是学号 **13** 对应的课程大作业网站。按照作业分组规则，学号 13 对应第 13 类 **加工**，因此本项目完成加工类别下的 5 个子类别案例：常减压装置操作优化、催化裂化产物预测、炼化设备预测性维护、化验数据智能审核、产品质量在线软测量。

项目是一个纯前端静态网站。页面把每个案例拆成“专业背景、案例流程、交互演示”三部分，读者可以先看工艺问题，再看模型怎样处理数据，最后拖动参数或筛选样本观察结果变化。所有演示数据都是教学合成数据，结果由浏览器中的 JavaScript 实际计算，不代表工业生产标准。

代码仓库：[Dutu007/refinery-lab-processing-cases](https://github.com/Dutu007/refinery-lab-processing-cases)

## 快速运行

直接双击 `index.html` 即可打开网站，不需要安装依赖、启动后端或连接 CDN。也可以在本目录执行：

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:5173/`。如果从项目上一级目录启动服务器，访问地址是 `http://127.0.0.1:5173/workspace/`。

## 五个案例

| 场景 | 主要方法 | 演示重点 | 难度 |
| --- | --- | --- | --- |
| 常减压装置操作优化 | 二次岭回归、约束搜索 | 调整炉温、回流比和压力，比较收率、能耗与闪点约束 | 中 |
| 催化裂化产物预测 | 距离加权 k 近邻回归 | 改变反应条件，观察六类产物收率和测试误差 | 高 |
| 炼化设备预测性维护 | 多变量高斯异常检测 | 比较联合测点异常与单一振动阈值的报警时间 | 中 |
| 化验数据智能审核 | 孤立森林、范围规则 | 结合规则和模型，逐条说明为什么需要人工复核 | 低 |
| 产品质量在线软测量 | 岭回归、残差区间 | 用连续过程变量估计两次化验之间的产品质量 | 中 |

## 目录结构

```text
workspace/
├─ index.html                         网站入口
├─ README.md                          仓库首页说明
├─ README.txt                         原静态项目说明
├─ docs/
│  └─ 项目说明与作业提交指南.md       完整项目和作业文档
├─ assets/                            页面、数据、导入器和内置案例包
├─ cases/                             五个可独立导入的案例文件夹
│  ├─ 加工-常减压装置操作优化/
│  ├─ 加工-催化裂化产物预测/
│  ├─ 加工-炼化设备预测性维护/
│  ├─ 加工-化验数据智能审核/
│  └─ 加工-产品质量在线软测量/
└─ tools/
   ├─ build.mjs                       打包案例资源并更新版本号
   ├─ check.mjs                       数值、案例契约和导入检查
   ├─ create-content.mjs              生成维护用内容
   ├─ engine.js                       案例共用数值函数和图表函数
   └─ demo.css                        案例共用演示样式
```

每个案例文件夹都能单独提交，结构保持为：

```text
加工-某个具体场景/
├─ case.json
├─ README.txt
└─ demo/
   ├─ index.html
   ├─ demo.css
   ├─ engine.js
   └─ demo.js
```

## 修改、构建和检查

修改 `cases/` 下的 `case.json` 或 `demo/` 内容后，在 `workspace` 目录执行：

```powershell
npm run build
npm run check
```
