# 产品质量审查与改进记录

审查基线：main `ba478648` 与本分支当前代码。本文只记录项目运行质量，不包含课程提交物、姓名学号或发布链接。

## 项目定位与已验证边界

- 这是一个可离线打开的教学交互平台，五个案例均使用明确标注的合成数据和简化模型。
- 案例包遵循 `case.json + demo/` 契约，导入器会校验文件名、大小、类型、重复 ID 和必要字段。
- 页面模式在 sandbox iframe 内运行；模块模式只允许通过 `mount(root, api)` 更新自己的 Shadow DOM。
- 合成数据、固定随机种子和简化阈值不能推导真实装置精度、生产联锁或操作规程；项目文案应继续保持“教学演示”标签。

## 本轮发现与处理

### P0：模块演示可越过宿主边界（已修复）

此前导入的 `demo.js` 通过 `new Function` 在主页面执行，若脚本主动调用网络、浏览器持久化或动态代码能力，可能影响站点状态或带出数据。

本分支现在在两层拦截：

1. 导入校验拒绝包含 `fetch/WebSocket/XMLHttpRequest/EventSource/sendBeacon`、`localStorage/sessionStorage/indexedDB/document.cookie`、`eval/Function/importScripts` 的模块脚本；
2. 运行时宿主再次检查并阻止已保存的旧案例，避免只依赖导入时校验。

需要外部资源的案例应使用整页模式，并把资源放在案例包内；页面模式仍运行在 sandbox iframe，且资源被内联为 data URL。

### P1：测试与维护（已补强）

- CI 使用 Node 22 执行 `npm run build` 与 `npm run check`，权限仅为 `contents: read`。
- 检查脚本覆盖案例契约、数值结果、页面结构和 bundle 一致性；每次修改案例源文件后必须重新构建。
- 当前没有真实移动设备矩阵或浏览器自动化，因此不能仅凭 CI 宣称完成所有浏览器兼容性验证。

## 仍需优先优化的项目事项

1. **真实浏览器回归**：补充至少一个桌面 Chromium 和一个窄屏/触摸配置的自动化流程，验证导入预览、键盘焦点、案例切换、下载与恢复。
2. **运行可观测性**：为案例宿主提供统一的错误事件和开发模式日志开关，生产界面只显示可读错误，不泄露脚本内容。
3. **性能预算**：记录首页首次加载、案例切换后的内存与定时器清理；导入包保持 6 MB 上限，避免把大图重复编码进 bundle。
4. **教学透明度**：每个案例继续展示输入范围、单位、数据生成假设、随机种子和适用范围；模型指标应标注“教学数据上的示例值”。
5. **兼容降级**：验证无 `crypto.randomUUID`、无 Shadow DOM 或禁用本地存储时的友好提示，不把浏览器特性失败变成白屏。

## 验收方式

```bash
npm run build
npm run check
```

CI 不访问生产服务、不需要 secrets，也不会部署。真实浏览器、真实手机和工业数据仍是项目外部限制，不能由静态检查替代。
